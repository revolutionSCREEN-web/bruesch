Felder auf dem Rad

Die Reihenfolge entspricht der Reihenfolge im Rad. Rad-Text: was auf dem Feld steht – // erzeugt einen Zeilenumbruch. Mengen: Stückzahlen je Messetag; leer = unbegrenzt. Der Artikel mit der doppelten Menge wird automatisch doppelt so oft ausgespielt.

preise.txt

Diese Datei muss neben index.html liegen. Zum Übernehmen entweder herunterladen und ins Repo revolutionSCREEN-web/bruesch (Ordner glueckrad/) legen, oder den Text kopieren und die Datei dort direkt auf github.com bearbeiten. Nach dem Speichern baut GitHub Pages automatisch – etwa ein bis zwei Minuten, dann zeigt das Display die neuen Preise.
